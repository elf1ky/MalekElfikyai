# 🎓 منصة التعلم الذكي v4.0

منصة تعليمية للفصول الدراسية — 9 فصول، كل فصل بكتابه وأسئلته وامتحانه.

## ✨ المميزات

### 📚 الفصول الدراسية
- **9 فصول** — كل فصل منفصل بمحتواه
- **📖 كتاب الفصل** — رابط PDF خارجي (Google Drive/Dropbox/أي رابط)
- **❓ أسئلة الفصل** — أسئلة تفاعلية مع تقييم ذكي
- **📝 امتحان الفصل** — رابط امتحان خارجي (Google Forms)
- **🤖 محادثة الكتاب** — RAG يجيب من الكتاب المرفوع

### 🔒 أمان
- كود سري للمعلمين
- Rate limiting
- Turso قاعدة بيانات سحابية

## 🚀 التشغيل

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 🌐 النشر

1. ارفع على GitHub
2. انشر على Streamlit Cloud
3. أضف Secrets:
```toml
GROQ_API_KEY = "your-key"
TURSO_DATABASE_URL = "libsql://..."
TURSO_AUTH_TOKEN = "..."
```

## 📁 الملفات

| الملف | الوظيفة |
|-------|---------|
| `app.py` | تسجيل دخول + رئيسية |
| `database.py` | قاعدة البيانات (الفصول + الكتب + الأسئلة) |
| `security.py` | الأمان |
| `ai_service.py` | الذكاء الاصطناعي (RAG) |
| `pages/library.py` | 📚 الفصول الدراسية (الكل في واحد) |
| `pages/book_ai_chat.py` | 📖 محادثة الكتاب |
| `pages/notes.py` | 📝 الملاحظات |

## 🎓 كيفية الاستخدام

### المعلم:
1. يسجّل بحساب "معلم" (يحتاج كود سري)
2. يدخل "الفصول الدراسية"
3. ينشئ فصل جديد (اسم + وصف + رابط امتحان)
4. يضيف كتاب للفصل (رابط PDF أو رفع PDF للـ RAG)
5. يضيف أسئلة للفصل

### الطالب:
1. يسجّل بحساب "طالب"
2. يدخل "الفصول الدراسية"
3. يختار فصله
4. يقرأ الكتاب (رابط) + يحل الأسئلة + يدخل الامتحان
